# 픽샷 (PickShot)

"내 픽(Pick)과 찍은 샷" — 달조아랩 모바일 앱

- 패키지명: `com.daljoalab.pickshot` (Android applicationId / iOS Bundle ID 공통)
- 저장소: https://github.com/juyunyoung/pickshot

## 폴더 구성
- `document/` — 기획 문서 ([PRD](document/PRD.md), 시작 문서)
- `app/` — 모바일 앱 (안드로이드·iOS) — 생성 예정
- `admin/` — 관리자 웹 — 생성 예정
- `supabase/` — DB 마이그레이션, Storage, Edge Functions — 생성 예정

> `.env` 등 비밀 값은 절대 커밋하지 않는다.
